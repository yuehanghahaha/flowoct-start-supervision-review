# 整卷 3D OCT→OCTA 流匹配实验方案

设计日期：2026年11月16日。全时间监督修订日期：2026年11月16日。目标平台为单张 A100 80GB。方案承接 exp131 提出的问题，以固定患者划分完成一次正式训练、验证选模和测试回传。参数量和单张量显存为静态计算，实际峰值与吞吐由服务器原尺寸验收给出。

## 1. 科研问题与方案选择

exp131 的 E110 已生成部分粗血管和层状结构，仍可见亮点和断续细血管。其第 113 轮累计完成 22,600 次更新，每位患者的每个高频核心平均被抽到约 10 次。10301 单例的目标高频系数 RMS 约 0.0245。14:30 的设备占用为 6.47 GiB，训练日志的张量分配峰值为 4.64 GiB。设计以这三项观察为出发点，机制归因仍需由新结果验证。[阶段分析](experience/exp131_20261111_haar_axialmamba_a100_200e/verification/interim_analysis_20261116_140227/REPORT.md) · [显存与子带诊断](experience/exp131_20261111_haar_axialmamba_a100_200e/verification/MEMORY_AND_LEARNING_20261116_143038.md)

本方案训练一个 **Haar 子带尺度校准、带高斯参考速度的整卷 CNN–Mamba 条件流**。用训练集统计量调整各频带的有效噪声尺度。把沿直线混合路径可解析的高斯参考速度固定下来，网络回归剩余速度。每个采样时刻同时计算残差速度、估计端点的体素及分层投影损失，精确起点额外增加采样次数。OCT 多尺度特征在整卷 CNN 与 Mamba 中融合，所有低频和高频位置都参与每位患者的速度监督。

主要科研假设是 **校准高频目标、全时间端点监督及精确起点采样，有助于模型利用患者的 OCT 恢复细节**。全卷监督增加每次更新覆盖的结构范围。这里同时改变路径尺度、速度参数化和网络，完整实验回答组合是否有效，各项贡献需要后续独立研究。

## 2. 数据和生成路径

- 沿用 OCTA-3M 固定 **140 训练 / 10 验证 / 50 测试**病例绑定。整卷 ZYX 为 **256×304×304**，OCT/OCTA 都固定除以 255。训练使用原配准体积和层面坐标。实验注册时记录实际数据路径、患者名单和文件身份。
- 一级正交 3D Haar 保留八个子带，顺序按 exp131 的 LLL、LLH、LHL、LHH、HLL、HLH、HHL、HHH。每带网格均为 **128×152×152**。
- 对训练 140 人的 OCTA，按子带用 float64 累积全卷平方和与元素数，取 $s_b=\max(\sqrt{\mathrm{mean}(W(y)_b^2)},1/255)$。同样从训练 OCTA 统计原体积 RMS $d$ 和浅层及深层最大投影的有效射线 RMS $m_s,m_d$，三者均下限 1/255。投影 RMS 使用训练 GT 层面。冻结这些统计，随配置保存统计样本、计数和输入哈希。
- 网络的条件为配对 OCT 的 Haar 八带，由独立的浅层 CNN 编码。OCTA 真值构成训练目标与训练路径，GT 层面用于训练投影损失与生成后的评价。正式推理只接收 OCT 和独立噪声。
- 在归一化子带中取 $z_1=W(y)/s$，$z_0=\epsilon\sim\mathcal N(0,I)$。各患者的噪声独立。训练路径 $z_t=(1-t)z_0+t z_1$，目标速度 $u=z_1-z_0$。换算回原 Haar 空间，起点的第 $b$ 带噪声 RMS 为 $s_b$，这是相对 exp131 的科学设置变化。

令 $q(t)=(1-t)^2+t^2$，高斯参考速度为

$$v_{\mathrm{ref}}(z_t,t)=\frac{2t-1}{q(t)}z_t.$$

两端为独立标准高斯的参考情况下，中间边缘协方差为 $q(t) I$，上式生成这条边缘路径。真实 OCTA 的非高斯结构及其 OCT 条件关系由网络学习。模型输入状态 $z_t/\sqrt{q(t)}$，输出八带残差速度 $r_\theta$，总速度为 $v_{\mathrm{ref}}+r_\theta$。损失直接回归

$$r^*=u-v_{\mathrm{ref}}=\frac{(1-t)z_1-tz_0}{q(t)}.$$

因此残差平方误差与总速度平方误差相同，且分母始终至少为 0.5。在精确 $t=0$，$v_{\mathrm{ref}}=-z_0$，残差目标恰为全部归一化 OCTA 系数 $z_1$。首步端点估计就是 $W^{-1}(s\,r_\theta)$。这使单靠预测负噪声的策略在起点无法获得很小的归一化高频损失。直线插值参考标准流匹配，高斯参考项由本方案对上述路径推导。[Flow Matching §3–4](https://arxiv.org/html/2210.02747v2#S4) · [作者仿射路径代码](https://github.com/facebookresearch/flow_matching/blob/main/flow_matching/path/affine.py)

子带尺度校准、状态输入标准化、高斯参考速度和残差速度回归覆盖整个时间区间。所有采样时刻复用同一次预测，构造端点

$$\hat z_1(t)=z_t+(1-t)\left[v_{\mathrm{ref}}(z_t,t)+r_\theta\!\left(z_t/\sqrt{q(t)},t,\mathrm{OCT}\right)\right],\qquad
\hat y(t)=W^{-1}\!\left(s\,\hat z_1(t)\right).$$

若 $r_\theta=r^*+\delta r$，有 $\hat z_1-z_1=(1-t)\delta r$。体素和投影损失对速度输出的梯度也会经由 $(1-t)$ 缩放。靠近终点时速度 MSE 继续监督残差，端点项自然减弱；在精确 $t=1$，路径状态已等于目标，端点项为零。均匀训练时间取开区间 $(0,1)$，精确起点由单独采样提供。采用有界系数保留这一时间权重，避免接近终点时引入除以极小数的放大。这是预先声明的目标设计。全时间单步端点估计参考 FlowOCT 的随机时间前向计算。[FlowOCT 作者前向实现](https://github.com/cnu-medilab/FlowOCT/blob/2309126956d2b80a95f2d307d85a50799cc658a6/models/FlowOCT_model.py#L115)

## 3. 网络结构与参数量

以下空间维度均为 ZYX，通道独立列出。S0、S1、S2 分别为 128×152×152、64×76×76、32×38×38。每位患者只使用一份配对 OCT。

| 路径 | 网格 | 层宽、深度和融合 |
| --- | --- | --- |
| OCT 条件 O0 | S0 | 3³ Conv 8→32，1 个 32 通道卷积残差块 |
| OCT 条件 O1 | S1 | 2³ stride-2 Conv 32→64，1 个 64 通道残差块 |
| OCT 条件 O2 | S2 | 2³ stride-2 Conv 64→96，1 个 96 通道残差块 |
| 状态编码 E0 | S0 | 归一化状态 8 通道与 O0 融合，1³ Conv 40→48，2 个 48 通道时间条件残差块 |
| 状态编码 E1 | S1 | 2³ stride-2 Conv 48→96，与 O1 拼接后 1³ Conv 160→96，2 个 96 通道时间条件残差块 |
| 状态编码 E2 | S2 | 2³ stride-2 Conv 96→128，与 O2 拼接后 1³ Conv 224→128，1 个 128 通道时间条件残差块 |
| 全局 Mamba | S2 | E2 由 Linear 128→384 投影为 46,208 个 token，加入三维位置编码。12 块，宽 384，FFN 隐宽 1,536 |
| 解码 D2 | S2 | Mamba 输出经 LayerNorm 与 Linear 384→128，和 E2 拼接，1³ Conv 256→128，1 个 128 通道时间条件残差块 |
| 解码 D1 | S1 | D2 经 1³ Conv 128→96 后三线性上采样，与 E1 拼接并经 1³ Conv 192→96，2 个 96 通道时间条件残差块 |
| 解码 D0 | S0 | D1 经 1³ Conv 96→48 后三线性上采样，与 E0 拼接并经 1³ Conv 96→48，3 个 48 通道时间条件残差块 |
| 输出 | S0 | 逐位置 LayerNorm，1³ Conv 48→8，生成一低频、七高频残差速度 |

卷积残差块使用 3³ depthwise Conv、逐体素通道 LayerNorm、1³ 通道扩张 C→2C、SiLU、1³ 投回 C，加输入残差。时间条件块在归一化之后用 384 维时间向量产生 shift 和 scale。局部归一化有 affine 参数，eps 为 1e-6。上采样采用 align_corners=False，卷积在 3³ 时 padding=1，1³ 时 padding=0。下采样卷积核 2³、stride=2、padding=0。所有卷积含偏置。

时间嵌入为 128 维正余弦与 Linear 128→384→384，中间 SiLU。令 64 个频率为 $\exp(-\log(10000)j/64)$，相位乘 $1000t$。位置编码为 Linear(3,384,bias=False)，输入是 S2 对应的归一化体素中心坐标。

12 个 Mamba 块按 Z、Y、X 循环四次。每块只沿一个轴取线，正向与反向用同一模块，输出翻回后平均。各患者及各空间线分别扫描，一个体积前向共 24 次方向调用。用官方 Mamba v1 的 $d_{state}=16$、$d_{conv}=4$、expand=2、dt_rank=24，输入与输出投影沿用官方无偏置。Mamba 与 FFN 分别先经逐 token LayerNorm，affine 关闭，再用时间条件产生各自的 shift、scale 和残差门。FFN 是 Linear 384→1536、GELU、Linear 1536→384。时间调制和最后八带输出层零初始化，Mamba 保留官方内部初始化。其余普通卷积和线性层使用 PyTorch 默认初始化。从随机初始化训练。

| 参数组成 | 参数数 |
| --- | ---: |
| 全局 Mamba、FFN、投影、坐标和全局调制 | 36,489,344 |
| 局部状态编码与解码 CNN、八带头 | 1,286,472 |
| 三尺度 OCT 编码 | 136,320 |
| 共享时间嵌入 | 197,376 |
| **设计合计** | **38,109,512** |

每个官方 Mamba 模块按源码的层规格为 963,840 参数。每块加上两层 FFN 和 384→2304 调制后为 3,032,448。单份 float32 权重约 152.44 MB。正式实现以实际模块参数计数复核本表。[官方 Mamba v2.2.4 源码](https://github.com/state-spaces/mamba/blob/v2.2.4/mamba_ssm/modules/mamba_simple.py)

## 4. 训练清单

| 项目 | 固定设置 |
| --- | --- |
| Batch | **2 位不同患者的完整体积**，独立噪声，并按下方规则分别取时间 |
| 一轮 | 200 次成功优化器更新，400 次患者访问。用从固定训练名单导出的两次完整随机排列和第三次排列的前 120 项 |
| 总训练 | **200 轮，40,000 次成功更新，80,000 次患者访问** |
| 时间采样 | 每轮随机选中的 100 个 batch 各有一位患者用精确 t=0，锚定患者位置随机。其余 300 个患者样本取 U(0,1)，共 25% 精确起点、75% 连续时间。全部 400 个患者样本计算速度、体素和分层投影损失 |
| 优化器 | AdamW，β=(0.9,0.999)，eps=1e-8。衰减 0.01，偏置、归一化参数及 Mamba 官方标记的免衰减参数为 0 |
| 学习率 | 前 2,000 次成功更新线性升至 1e-4，之后按成功更新号余弦衰减至 1e-5 |
| 梯度与 EMA | 每次用两位患者等权平均损失，反传后全局梯度范数裁剪 1.0，AdamW 更新后 EMA 更新一次，衰减 0.9995 |
| 随机性 | 主种子 12920261111。患者、选起点标记、均匀 t、噪声分别用固定派生规则。保存每步患者身份、t、噪声种子和成功更新数 |
| 精度 | float32 参数、输入、状态、运算接口和损失。matmul 和 cuDNN 允许 TF32。AMP 与 scaler 关闭。cuDNN benchmark 开启，deterministic 关闭。按此验收实际开关 |
| 训练日志 | 逐患者记录采样 t、低频和高频速度误差、全时间端点体积与投影损失，逐 batch 记录全局梯度范数、两个 t、学习率及成功更新。每轮对精确 t=0 单独汇总，对其余 t 按十个等宽时间箱汇总损失与样本数。按轮保留时长、峰值 allocated/reserved、读取耗时和实际设备采样 |

每位患者的主损失是低频残差 MSE 乘 1/8，加高频七带合并 MSE 乘 7/8。各子带全卷监督。每个采样时刻都使用真实体素域的估计端点及分层投影损失：

$$L_i=L_{\mathrm{FM},i}+\min(k/1000,1)\left[
0.10\,\frac{\mathrm{MAE}(\hat y_i,y_i)}{d}
+0.20\left(0.75\,\frac{L_{s,i}}{m_s}+0.25\,\frac{L_{d,i}}{m_d}\right)\right].$$

$k$ 为即将完成的成功更新号。$L_s$、$L_d$ 分别是 ILM–OPL 与 OPL–BM 最大投影的有效射线 L1，在逆 Haar 后用预测与 GT 的同病例层面计算。训练端点保留原值。两位患者均计算完整损失，求和后除以 2。全时间辅助项前 1,000 次成功更新线性升至声明权重，之后每次生效。相对初稿仅监督起点的安排，每轮参与辅助项的患者样本从 100 增至 400；体素系数 0.10、投影系数 0.20 是此次修订保留的名义系数。实际优化贡献随 t 和梯度变化，按时间箱记录原始值和加权值。幅度校准和辅助项系数属于本方案的预设实验选择。

按 16 个等面积横向高频核心计，exp131 每成功更新监督 1 个核心。本方案每更新有 2 份全卷，相当于覆盖 32 个这样的区域。这里比较的是被监督的空间面积，同患者位置之间相关。新旧 40,000 次优化器更新相同，患者访问与空间监督量有差异，最终用途是完整设计的性能评价。

## 5. A100 80GB 如何使用

显存优先用于 **两位患者的全卷特征与反传激活**。以计划的 B=2、float32 为例：

| 单项规模 | 估算 GiB |
| --- | ---: |
| 整卷八带状态，2×8×128×152×152 | 0.176 |
| 一个 S0 的 48 通道特征 | 1.058 |
| 一个 S0 的 96 通道扩张特征 | 2.115 |
| 一个全局 384 通道 token 特征 | 0.132 |
| 权重、梯度、EMA、AdamW 两个动量合计主体 | 0.710 |

真实训练同时保留多层激活、SSM 扫描缓存及算子工作区。上表用于分辨显存来源，峰值须用实际软件和训练循环测定。

1. **优先验收真实 B=2。** 使用两位训练患者的原尺寸数据和完整流程，跑官方 Mamba 正反向、CNN、Haar、AdamW 和 EMA，两位患者同时计算全卷体素和浅深投影损失并完整反传。覆盖一个精确起点加均匀 t，以及两个均匀 t 两类 batch，并包含接近 1 的时刻。各执行配置在独立进程里热身至少 5 步，待 AdamW 状态和 cuDNN 工作区初始化后，再测至少 20 个稳定更新。统计预取、传输、GPU 计算和完整更新耗时。
2. **选择性保留激活。** 初始验收从全局 12 块和 S0 的编码、解码残差段开启非重入重计算。较粗 CNN 和 OCT 编码保留激活。随后分段减少重计算，在固定形状与输入上衡量整卷每秒、每更新用时及峰值。优先发布带有已测吞吐收益的保留策略。CUDA 重计算保存的是执行策略，模型结构、有效 batch 和科学预算固定。[PyTorch 2.5 checkpoint 文档](https://docs.pytorch.org/docs/2.5/checkpoint.html)
3. **给系统留明确余量。** 预热后测 PyTorch 张量分配峰值、分配器预留峰值和设备占用采样。整套训练和推理验收以设备采样峰值约 72 GiB 内、可用显存约 8 GiB 以上为运行目标。显存余量有吞吐收益时用于保留激活。若原尺寸真实 B=2 在选择性重计算下仍超过预算，预先登记两个 B=1 全卷微批及梯度累积，两份损失各乘 1/2，累计后只裁剪、更新、更新 EMA 一次。先核对有效批的损失和梯度，正式运行中固定已验收的执行策略。
4. **重计算减下来后测数据端。** 让 CPU 预取完整配对体积、固定页内存异步拷贝和 GPU 计算重叠，队列上限两组有效 batch。保留原有归一化与采样顺序。配对 float32 训练整卷的磁盘缓存约 24.68 GiB，按实测 I/O 和持久盘空间决定是否启用，在用户目录内独立记录身份。
5. **控制全卷计算量。** 局部块使用 depthwise 空间卷积加两层 pointwise 通道混合。一位患者的全局 12 块共 24 次方向调用。对 2 位患者，最细五个速度 CNN 块的一次前向核心卷积算术量约 0.62 TFLOP，尚需计入其他层、搬运与反传。实际瓶颈由热身后计时定位。

参数和数据规模已固定，租期按实测速度推算。若包含全时间三项监督的完整优化一步分别为 2.5、4 或 6 秒，训练循环分别约 **27.8、44.4 或 66.7 小时**。另加 40 次 10 人验证、50 人正式测试、10 人条件诊断及固定时间探针和持久化开销。总耗时以实测验证整条流水线推算，预热、快照和完整验证单独计时。

## 6. 推理、验证与科学判据

- **正式推理**使用验证或测试患者固定高斯种子。独立计算 OCT 的三尺度条件一次并在同卷各求解步复用。以 $t=0$ 到 $t=1$ 的 **Heun16** 在整卷八带状态上积分，共 32 次速度计算。恢复子带尺度后一次逆 Haar，记录小于 0、大于 1 的比例，再固定裁剪至 [0,1]。正式评价为 ZYX=256×304×304。
- **选模**使用 EMA。每 5 轮在固定 10 人的整卷验证上计算全套指标，记录 E5 至 E200 共 40 次。主指标为 ILM–OPL 最大投影 SSIM 的患者等权均值，同分取较早轮。完整训练与验证结束后冻结该 best 的身份。
- **标准结果**统一采用同一份 best。完整 3D 体积、沿 Y 的 304 张逐 B-scan、ILM–OPL 最大投影、OPL–BM 最大投影、全 Z 均值和最大投影、ILM–OPL 均值、OPL–BM 均值及 ILM–BM 均值，九组各报 MAE、PSNR、SSIM。固定 data_range=1，PSNR 为 $-10\log_{10}(\max(\mathrm{MSE},10^{-12}))$。SSIM 用均匀窗口 7 和样本协方差，完整卷计算三维 SSIM，切片和投影计算二维 SSIM。B-scan 先整卷平均后患者等权。层面用原生 Z640 一基坐标映射至 Z256 的体素中心，最大投影两端闭区间，浅层均值上端开区间，深层与 ILM–BM 均值两端闭区间。留存原数值与同窗图。
- **检验有没有用患者条件。** 冻结 best 后，在验证患者中按名单固定循环置换 OCT，保持 checkpoint、起点噪声、ODE 和原患者的 GT 层面一致，与配对推理逐人对照。记录整卷、切片与投影三指标。另用固定的配对路径状态，在 t=0、0.125、0.25、0.5、0.75、0.875、0.9375 分别比较正确 OCT 和置换 OCT 的八带速度误差与估计端点误差。较大 t 的路径状态含有更多真实目标信息，结合低 t 和完整生成判断条件依赖。重点看正确 OCT 是否改善与原患者对齐的粗细血管，以及额外亮点是否降低。这是对已有权重的诊断。正式选模与测试均使用配对输入。
- **正式测试**冻结后自动执行固定 50 人。每例保留完整预测、原指标、投影及病例图片，三维 float32 预测合计约 **4.41 GiB**。中间验证只保留指标、二维数值投影和有用配图。结果目录包含学习曲线、患者/切片指标、完整集汇总、条件诊断、配置、来源、权重身份、运行调度及文件校验。按目录回传。患者特异配对提高而整卷或深层出现下降时，报告对应取舍。

条件利用得到支持需同时看各固定 t 的高频误差、配对与置换 OCT 的逐患者差，以及全卷生成的同窗证据。全时间端点监督在真实配对路径状态上计算，完整生成从模型自身状态继续积分，两种状态下的表现都记录。浅层最大投影 SSIM 是正式选模量，主结论还结合深层与三维指标。与 exp131 比较时使用两边各自原规则的 best 并注明可用验证窗口，正式测试按共同固定划分比较。只用同一评价口径的保留证据，完整 27 指标逐项报告。

## 7. 实现、验收和恢复

- 落地时用下一个未使用的实验编号和独立目录。写清与 exp131 的差异，保留已有实验源码及输出。确认实际数据绑定后复用 A100 已有 lyh_flowoct 和 lyh_tmux，校验版本、GPU UUID 和持久化目录映射。缓存、环境使用记录、代码和结果位于本人目录。
- 对照验收包括 Haar 往返和能量、全体积形状、速度分解和端点误差恒等式在 t=0/1 及区间内成立、接近终点时的有限梯度、所有采样时刻的体素与浅深投影损失、层面投影与原指标一致、batch 的两个患者同时获得梯度、断点恢复的序列一致性。用合成张量核对并行 B=2 和有效 B=2 累积的数学关系，再用训练病例做已获配 GPU 的有限验收。验收指标从正式训练中单独留档。
- 在 full batch 的成功更新边界检查暂停标记，落盘模型、EMA、AdamW、学习率进度、训练和优化器计数、固定采样位置、CPU/CUDA RNG 以及阶段状态。每轮都原子提交 latest，更新 best 时单独写入。运行版本、精度和重计算策略一并记录。恢复时按指纹验明配置、权重和固定患者绑定，继续原预算。验证和测试按已完成患者幂等继续。
- 用 lyh_tmux 独立会话跑正式训练。状态、日志、暂停和恢复入口随代码交付。作业依次执行正式训练、冻结 best、正式测试和结果校验。资源有效期通过平台核对，跨租期从持久化检查点继续。实际上传、GPU 验收、启动和结果分别登记。正式数据与模型运行从用户获配且授权的 slot 进入。
