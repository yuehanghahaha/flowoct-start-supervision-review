# 相对深度子层监督

Exp181 继承 [Exp176 的发布提交](https://github.com/yuehanghahaha/flowoct-start-supervision-review/tree/4ebd97e85e9384e7a0c2c101f69e6c630d762402)。整层最大投影会丢掉最大值的轴向位置。子层投影把同一条 A-line 上的信号分开比较，使一部分跨子层错位进入训练目标。

## 分区定义

| 相对深度 | 子层 |
| --- | --- |
| [0, 0.25) | 1，靠近 ILM |
| [0.25, 0.5) | 2 |
| [0.5, 0.75) | 3 |
| [0.75, 1] | 4，靠近 OPL |

在每个横向位置分别读取已对齐的 ILM 与 OPL 边界（层通道0与2）。边界是一基原始深度坐标，先减一得到零基坐标 ℓ、u，再用相对深度 r = (z − ℓ)/(u − ℓ) 划分。实现直接在同一原始坐标中构造区间边界，分区随 A-line 的层面位置和厚度变化。原始轴深640、重采样后深度D=256时，重采样体素 i 的中心映射为 z = (i + 0.5) × 640 / D − 0.5。若实际数据轴向做了额外裁剪，需要先验证或修正层面坐标对齐。

内部边界归后一段，OPL 端点归末段。重合或无效层界、没有体素中心的射线子层会从误差均值中剔除。图中这些位置填0，`projections.npz` 内的有效掩码可区分无支持与实际零强度。分区只解释 ILM–OPL 内的相对位置，四段是计算区间。OPL–BM 仍由原体素损失及标准投影评价覆盖。

## 训练目标

对预测端点 ŷ 和 GT OCTA y，在同一子层内沿 Z 取最大值。设 Aₖ 为有效射线集合，M 为该核心内非空子层数。每核心的原强度误差为

$$
L_{\mathrm{raw}} =
\frac{1}{M}
\sum_{k:\lvert A_k\rvert>0}
\frac{1}{\lvert A_k\rvert}
\sum_{(a,b)\in A_k}
\left| P_k(\hat y)_{a,b} - P_k(y)_{a,b} \right|.
$$

四子层均有效时就是四项 L1 的等权均值。M=0 时该核心的新项值和梯度均为0。每位患者的两个全深度核心等权，横向 halo 不计入该项。用父实验定义的训练集整层 ILM–OPL MIP RMS m 缩放 L_raw。总损失中加入系数0.15的 L_sub = L_raw/m，沿用 s/1400（上限1）的辅助项渐进系数。该系数和 K=4 是预先声明的设计选择。所有采样时刻都计算同一个目标，端点对速度的梯度随 1−t 缩小。

模块用 FP32 完成边界和误差运算。每次处理一个子层，不构造 K×完整体积的展开。最大值通过被选中的体素传递梯度，并列时取第一个最大值对应体素。目标由已有 GT OCTA 直接计算，网络推理输入仍是 OCT 与当前流状态。在一次速度预测得到的端点上计算，额外算子只负责投影与差值。

## 验证与解释

生成器每10轮使用同一批10位验证患者进行完整体积推理，计划 E10–E200 共20次。二维监督模型维持每250次更新的独立验证。选模沿用 Exp176 的加权验证 MAE；比较时需报告各自的验证窗口与频次，因为原 Exp176 的候选轮次更密。

每次验证与正式测试保留原九组三指标。另有 `depth_diagnostics.csv`、`summary.json` 的 `depth_diagnostics` 字段和每患者 `subslabs.png`。子层 MAE 用 /255 后的原强度直接计算，先在每层有效射线上平均，再做分层及患者宏平均。每项宏平均记录实际参与的患者数，避免将无有效覆盖的患者当成零误差。对照图各段使用统一显示窗 [0, 0.5]，数值以投影数组及 CSV 为准。验证只留二维投影和指标。正式测试按原协议保留三维预测。

| 合成操作 | 整层最大投影 L1 | 四子层最大投影 L1 | 含义 |
| --- | ---: | ---: | --- |
| 一个强度1的亮点从第1段移动到第2段 | 0 | 0.5 | 原位置的缺失和新位置的误检分别进入目标 |
| 同一亮点在第1段内移动 | 0 | 0 | 同一子层内部位置仍有歧义 |

因此子层误差可定位部分深度分配错误。体素位置、细血管被较亮峰值遮蔽的情况和三维连续性仍需结合三维误差、B-scan 与真实切片对照检查。合成反例验证了约束范围，患者上的改善幅度有待正式训练与评价。
