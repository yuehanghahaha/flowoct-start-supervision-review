# OCTA-500标注核查

核查依据为[数据集作者论文](https://arxiv.org/abs/2012.07261)，重点是3.2、3.5.1–3.5.5节；[IEEE DataPort](https://ieee-dataport.org/open-access/octa-500)为发布入口。DataPort页面受抓取限制。

论文列有毛细血管、大血管、动静脉、二维/三维FAZ和层边界。毛细血管标签由人工小块标注训练模型，再推广到投影、去除FAZ信号并做拓扑优化；不是全体素人工三维血管标注。相关血管标签对应二维B5投影视图。三维FAZ是三维无血管区，不能当作三维血管分割真值。

代码在匹配的二维投影上监督毛细血管，体积上使用重建、梯度匹配与按层界划分的四子层投影误差。子层的目标由 GT OCTA 强度计算，使用已有层边界。标签本身有模型加工偏差，独立视觉或人工审阅仍必要。

论文提供原始采集范围和尺寸，可推算名义采样间隔；但用户处理后的轴向裁剪/重采样未知，因此本配置spacing保持null，只报告表观像素宽度，不声称是真实毛细血管管径。

版本与标签编码必须在实际数据适配时确认；[标签适配要求](manifest_schema.md)与工具对此有显式校验。

## 用户下载目录的只读盘点

2026年11月17日12:50（UTC+8）仅检查用户持久化数据目录的名称与文件数：labels_native下有GT_Capillary、GT_LargeVessel、GT_FAZ、GT_CAVF、GT_Artery、GT_Vein、GT_FAZ3D、GT_Layers，各500文件。因此当前下载确实有相关标签目录，而不只是论文声称提供。

该盘点沿自 Exp176，只核实目录与文件数。500文件包含数据集两个 FOV，3M 固定成员、颜色编码、体积朝向与层面坐标仍待绑定验收。原始目录统计见 verification/dataset_inventory.json。
