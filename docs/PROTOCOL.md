# 研究协议

## 研究假设

持续高分辨率局部特征、跨尺度融合、局部结构均衡采样及作用于生成图像的血管监督，有望提高弱、小、连续的血管模式恢复，同时限制背景误检。当前代码不证明该假设，更不证明从结构OCT可唯一恢复真实血流。

生成器27,421,329参数，局部与时间模块98.01%；全局上下文545,104、其中Mamba算子204,480。二维监督模型111,779单列，训练后冻结。网络没有独立分割输出头，监督模型不接收OCT条件。

## 连续路径

仅训练集估计OCTA体素RMS d和ILM–OPL投影RMS m，float64累加，均设下限1/255。强度归一化为/255。

z1=y/d，z0~N(0,I)，zt=(1−t)z0+t z1，u=z1−z0。
q=(1−t)²+t²，v_ref=(2t−1)zt/q。
网络输入zt/√q及OCT/时间，输出残差r；总速度v=v_ref+r。
回归u等价于回归残差u−v_ref；端点估计yhat=d[zt+(1−t)v]。

解析项是高斯参考路径的速度分量，不代表真实OCTA边际服从高斯。它没有奇异的1/(1−t)，不能保证消除所有条件捷径。所有抽样时间使用同一组目标，含精确t=0；t接近1时端点梯度自然减弱，速度目标仍存在。

全卷zt来自同一整卷噪声与目标，局部裁块共享该状态和时间。训练全局上下文中的状态不是额外GT通道；生成时使用同一当前ODE状态。GT血管/层标注只参与训练损失、裁块位置及评价，不输入生成网络；推理时不需要这些标注。

## 裁块与无偏FM目标

沿Y/X把完整体积划为不重叠96²核心，保留末端不足96的有效区域。以有效体素数/全卷体素数抽取一个均匀核心，核心内速度MSE取均值。因此其期望等于整卷逐体素FM MSE。

第二核心按细中心线/FAZ环/血管/背景的固定混合取样。它仅用于辅助目标，不把这种GT偏置采样冒充均匀FM。两核心均保留完整Z=256射线，左右各32 halo；边界用clamped索引，只有有效核心进入损失。32像素覆盖二维监督模型13像素半径加上12次软骨架迭代的主要局部影响；它不保证整个深层生成器在任意裁块边界与无限上下文等价。

高分辨率流始终保留原体素坐标，不使用小波或横向预降采样。局部另外两尺度缩小2/4倍，保留最高分辨率主流并重复融合。3³、3×5×5和dilation(1,2,2)是体素单位的未发表设计选择，尚未根据实际spacing校准。

## 血管监督

先在140训练患者的GT投影/对应标签上训练二维监督模型3000更新；每250次对固定10人验证，按毛细/大血管平均Dice最大选择。冻结权重与哈希后进入流训练。

生成投影通过冻结模型计算类别概率。梯度保留到输入图像，监督模型权重不更新。它是可微损失工具，并非独立真值。

L = L_FM(uniform) + a(s)[.2 L_endpoint + .3 L_weighted_MIP + .1 L_vessel_CE + .1 L_capillary_clDice + .05 L_gradient_match]。
a(s)=min(s/1400,1)。辅助项是两核心各自有效区域的均值后等权平均。训练端点不裁剪。

- endpoint为体素L1/d。
- weighted_MIP为投影L1/m，以权重和归一化：普通背景/大血管1，毛细区域4，中等表观宽度中心线6，小中心线8，FAZ2；条件采用覆盖赋值，不意外叠加成更大的权重。
- 中心线在完整标签上先生成再裁块。像素表观宽度由标签距离变换得到，分界为3/7像素；不等于生理管径或光学分辨率。
- vessel_CE对生成图像经冻结模型得到的背景/毛细/大血管分类计算，毛细类加权；背景和FAZ均约束误检。
- soft-clDice仅对毛细概率图，预测软骨架在带halo图上生成后取核心，GT骨架来自完整图。与CE/强度误差联合；不宣称保留三维拓扑或获得论文二值理想条件下的保证。
- gradient_match比较3D相邻差分与GT差分，三个体素轴等权并除d。它是梯度重建，不是把输出抹平的TV，也不是有物理单位的导数。

## 优化与预算

AdamW、数值协议等完整参数见configs/main.json。200轮是真实患者遍历：每轮140人随机排列，两人一组70更新。每次统一优化器更新处理两人，每人两个局部核心；逐患者反向累积1/2损失，只在两人均完成后clip/step/EMA。每轮35位患者t=0、105位均匀t；独立整卷噪声。

生成器14,000次优化更新；另有监督模型3000次，不混算。每20次更新、每完整轮及暂停保存，原子替换且fsync。检查点包括AdamW/EMA/torch CPU与CUDA RNG、已提交更新、未完成轮次记录、待验证标记和best。

每个更新的患者、时间、裁块和噪声由独立稳定种子再现。暂停不会提交半个梯度累积组。断电/租期删除最多恢复到最后成功提交，不能承诺找回未提交更新或任意历史轮次。

## 推理、评价与选模

16步Heun、32次整卷速度评估。每次从同一个全局状态计算上下文，局部预测在核心上按Hann权重混合速度，再整体推进；禁止独立积分各patch。固定患者噪声，参数与状态精度分开记录，生成后再裁剪。

9组标准MAE/PSNR/SSIM：完整3D、逐Y的ZX B-scan、ILM–OPL max、OPL–BM max、full mean/max、ILM–OPL mean、OPL–BM mean、ILM–BM mean。data_range=1，均匀7窗口、样本协方差；B-scan先整卷再患者宏平均，其余也患者等权。投影输出YX，本协议各slab使用native640闭区间；不能未核对就与其他边界/归一化/投影协议混称可比，也不称为TransPro的V指标。

原选模规则为最小化.40毛细MIP MAE+.20毛细中心线MIP MAE+.20背景MIP MAE+.10大血管MIP MAE+.10体积MAE；患者等权，空类别不计该患者对应分量并重归一化，平分保留较早。它不依赖监督模型的分类结果，完整3D与各投影同时报告。

监督模型给出的毛细precision/recall/Dice、二维clDice、细中心线1px容差召回和FAZ误检是相关诊断，另列而不当作独立验证。没有三维毛细标签，所以不输出伪造的三维血管召回率。必要的独立视觉审阅仍待真实结果。

## 验收与留存

现有CPU测试覆盖完整宽度/深度模型在小空间张量上的前后向、冻结监督模型输入梯度、重计算梯度一致、路径恒等式、均匀采样期望、ODE同步融合及真实控制循环的暂停恢复。小张量仅为工程验证，不是交付的实验网络。

正式fit前还有使用真实训练患者的完整尺寸GPU验收：5次预热、20次计时以及全分辨率生成/27指标。失败时记录并退出，不自动缩小patch、分辨率、batch或科学预算。验收模型不继承到正式训练。

验证保留指标/二维图，不永久存中间3D；正式50人测试保存完整3D。测试逐病例哈希可恢复，预算完成并冻结身份前禁止开始。analysis_return提供训练和验证记录、原best验证/测试二维图、全部标准与结构诊断、源码/配置/输入身份和服务器三维清单，直接同步目录。
