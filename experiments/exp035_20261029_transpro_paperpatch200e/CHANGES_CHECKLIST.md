# TransPro修改与补充清单

实验：`exp035_20261029_transpro_paperpatch200e`。日期：2026-10-29。

公开基线为[ustlsh/TransPro固定提交dc748ea](https://github.com/ustlsh/TransPro/tree/dc748eac63ebffadfe191e96ef85e45e5d3539a0)，论文为[arXiv:2303.06807v2](https://arxiv.org/html/2303.06807v2)。本清单区分论文直接支持的修改、运行所需补充、保留的原代码行为，以及无法从公开资料确定的评价细节。它不是“所有内容均与作者历史运行相同”的保证。

## 一、仅三项论文依据的科学修改

三项都集中在`source/models/TransPro_model.py`。其余64个官方文件原样保留。原模型文件另存`provenance/TransPro_model.upstream.py`，逐行差异见`provenance/model_paper.patch`；可以恢复并核对，不依赖口头说明。

| 编号 | 官方原代码/README示例 | 本版修改 | 论文依据 | 实现解释及科学影响 |
| --- | --- | --- | --- | --- |
| P1 | 默认LSGAN；G使用真实标签MSE，D用真假MSE | 对抗项改为对数minimax；D使用真假BCEWithLogits，G使用`-BCEWithLogits(fake_score, 0)` | §3.1式(1)、(4)；§3.4式(13) | 原D保持无sigmoid的输出，BCEWithLogits内部稳定计算sigmoid和log。G等价于最小化`log(1-sigmoid(score))`，不是常见的非饱和`-log(D(fake))`替代。改变对抗目标和梯度，是此次用户授权的论文公式改动 |
| P2 | README传lambda_A=10、lambda_C=5，体积L1=10，投影/HCG/VPG共同乘5 | 仅将投影L1乘10；体积仍10、HCG和VPG仍5 | §3.1式(7)及其后文字：lambda1=lambda2=10；§3.4式(12)：alpha=beta=5 | 利用原lambda_A固定值10，不增加搜索或新权重。原选项lambda_C默认值其实为10，但官方README显式传5；本对照以该示例为准 |
| P3 | VPG先对UNet输出softmax，再比较两类概率L1 | 直接比较UNet原始两类logits的L1，仍乘5 | §3.3式(10)、(11)及“segmentation logits”的文字 | 保持原UNet、归一化、类数、索引和L1归约不变，仅删除softmax；改变VPG损失数值及梯度尺度 |

P1是按论文写出的minimax目标实现，不是发现了另一个作者代码版本。无法证明作者历史运行使用了该公式而非公开LSGAN；这项差异会随结果保留。

## 二、明确不改的作者行为

| 编号 | 保留内容 | 依据/边界 |
| --- | --- | --- |
| K1 | 原`generator3D(64)`、3D/2D判别器、UNet/HCG结构、通道数、初始化、BatchNorm、训练裁块256立方 | 公开模型代码；不缩网络、不加重计算、不改网络层或激活 |
| K2 | Adam、初始lr=0.0002、betas=(0.5,0.999)、batch1、主模型200轮 | 论文§4.3支持Adam、初始lr、batch和轮数；betas采用官方代码 |
| K3 | 作者G/D更新顺序、各自一次optimizer.step、零梯度方式；D总损失仍乘0.5 | `optimize_parameters`和`backward_D`原函数结构保持相同；论文未单独规定D实现的归约系数，本次不擅自删除原0.5 |
| K4 | 原LR调度器与调用时机，包括其在当前PyTorch下延后下降的行为 | 论文只给初始lr，没有公开后续曲线；不再自行改为100固定+100显式下降 |

| K6 | 每轮验证固定10人，每人一次作者随机256裁块，仅计算[-1,1] MAE，严格低于历史最佳时选best | 论文§4.3按验证MAE选模；具体裁块、模式及数值范围沿用公开训练脚本。没有扩大为每轮4窗口或八项指标 |
| K7 | 原DataLoader batch1、shuffle行为和4个worker；原裁块起点范围和no_flip | 作者数据加载选项及README命令。缓存读取接口替换见S2 |
| K8 | float32张量、不另加AMP/scaling；TF32及cuDNN由作者代码和框架默认决定 | 用户明确要求。记录实际TF32标志，不强制关闭、不加入确定性卷积约束，也不称允许TF32时为严格FP32计算 |
| K9 | 官方best、latest及编号轮次权重的触发条件、文件名和原保存函数 | 刷新best时存best及轮次；每5轮存latest及轮次；每5000次更新存latest。原调用仍生效，不默默跳过编号存档 |
| K10 | 作者默认seed选项和入口实际行为；不另外增加2026种子或确定性裁块序列 | 原入口没有应用seed选项，本版也不擅自应用；恢复已有运行时才恢复RNG |
| K11 | 原mean投影及随后的独立min-max、原训练输入各自min-max到[-1,1] | mean对应论文式(3)，额外min-max来自作者代码；不将代码规则说成论文明确要求 |

论文§4.3的VPG100轮RMSprop、HCG200轮是两份教师的预训练描述。本版使用作者发布的两份预训练权重，不重新训练它们，不把其历史精度、病例身份和轮次当成本次已验收事实。

## 五、验证证据及适用边界

- `verification/local_author_tests.json`：缓存裁块、只改声明的源文件、作者选项/worker、原LR时序、TF32标志不被覆盖、断点含教师BN/Adam、测试不可供训练使用。
- `verification/local_paper_loss_tests.json`：对数目标数值及梯度、执行实际补丁后的作者优化函数核对投影10/logits，以及未涉及方法的AST一致性。
- `verification/gpu_check.json`及服务器日志：以实际运行结果为准，不以本地合成测试冒充原宽度A800验收。
- `provenance/model_paper.patch`、`train_integration.diff`、`upstream_sha256.json`：供逐行及逐文件核对；`source/models/TransPro_model.py`以外的64份官方文件必须保持原指纹。

论文支持三项损失修改，不足以证明作者历史训练实际使用了这套修改。未公开的环境、原生深度预处理、教师训练身份、SSIM与标注身份始终保留为限制。后续不得把本版结果直接冠为“已完全复现官方历史数值”。

本次实际服务器验收已通过：A800 80GB、256立方、64通道，执行一次完整G/D更新，峰值allocated=24,532,891,136字节（约22.85 GiB），reserved=25,197,281,280字节。matmul TF32=False、cuDNN TF32=True、benchmark=True、deterministic=False；这些是实测结果，不是强制设置。合成首次更新含算法测速耗时约82.66秒，不用它直接外推正式200轮用时。数据准备通过，正式训练尚未开始。
