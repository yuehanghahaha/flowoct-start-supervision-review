# exp162 / exp163 配对实验协议

本次代码于2026年11月14日开始构建，11月15日继续完成。两个目录分别保存自己的科学配置、代码、标注、日志、检查点、预测和报告。

## 研究目标与父实验

A 使用 exp018 的速度 MSE 和精确 t=0 的 ILM–OPL 最大投影 L1。B 在相同路径上增加三个分层均值投影 L1，各系数0.1。A/B 使用同一初始种子、网络、训练患者索引、裁块、时间日程和数值设置。从头训练200轮，每轮200次成功更新，共40,000次。

历史 exp018 使用关闭TF32的float32及浅层最大投影SSIM选模。新A/B使用允许TF32的float32和四视图SSIM平均选模。A的训练损失继承exp018，完整报告会保留这些数值及选模差异。B增加的是分层监督及其强度，当前配对对照不能单独将收益归因于解剖范围而忽略总正则强度。

## 路径、终点与损失

O为源OCT，Y为真实OCTA。xt=(1-t)O+tY，v=vθ(xt,t,O)，监督终点 yhat=xt+(1-t)v。FM目标为Y−O，对全裁块全部体素计算MSE。

每轮100个精确t=0，另外100个从(0,1)均匀采样。仅t=0激活投影项，复用同一次网络前向。网络接收当前状态、时间和固定OCT条件。投影在原始有符号终点上计算，训练过程中保持速度与终点的梯度。

A总损失为 LFM + I[t=0] × 0.1 Lmax_ILM-OPL。

B总损失为 LFM + I[t=0] × (0.1 Lmax_ILM-OPL + 0.1 Lmean_ILM-OPL + 0.1 Lmean_OPL-BM + 0.1 Lmean_ILM-BM)。三项均值L1逐项求和，各自先按有效横向射线求均值。每项系数是0.1，均值项总系数0.3。ILM–BM覆盖前两层，三个损失有重叠监督。

## 层面、掩膜和空射线

Layer为[6,Y,X]、MATLAB一基原生Z640层坐标。Z256采样中心是(z+0.5)*640/256−0.5，对层面先减1。

最大投影继承exp018闭区间 ILM≤z≤OPL。非法深度设为负无穷后取最大值，保留负值终点的梯度。均值浅层使用ILM≤z<OPL，深层使用OPL≤z≤BM，整段使用ILM≤z≤BM。均值为掩膜内总和/(体素数+1e−6)，与项目保留的层均值评价定义相同。

每项L1仅对非空射线求均值。整项全空时返回可反传的有限零值，日志记录有效射线数。评分空射线输出零并记录数量。

训练层面来自对应训练病例人工标注，预测卷和真实卷使用同一掩膜。生成器不接收层面或二维幅度图。正式推理只输入结构OCT。

## 数值、优化和生成

网络为继承的四尺度base16 3D U-Net，2,097,521参数，显式源OCT条件，batch1，裁块ZYX256×64×64。每轮病例索引按exp018的独立NumPy日程采样，裁块沿用Python随机顺序。AdamW固定lr2e−4，weight_decay0，梯度范数上限1。

参数、输入、速度、终点、损失、优化器、ODE状态均float32。matmul TF32和cuDNN TF32允许，benchmark=True，deterministic=False，deterministic_algorithms=False。AMP、autocast和GradScaler关闭。软件版本、TF32环境覆盖值及实际标志单独记录。

验证/测试按完整256×304×304生成，Euler8，50%重叠，正可分Hann权重。每一步融合所有窗口速度后更新一个全局状态，只在最终输出裁剪至[0,1]。CPU保存全局浮点状态，GPU处理原64窗口，与exp018路径相同。

## 数据与A100路径

固定membership.json中的140/10/50患者。训练与验收不打开测试数组或标签。默认读取A100既有exp004的manifest.csv与cache/train_validation，原始数据位于/workspace/flowoct_work/data/OCTA500_v1/z256/3M。原清单可保留旧路径，绑定时按已冻结病例ID映射到指定Z256目录，同时保留原清单SHA及缓存对它的绑定证明。

准备逐例核对150名训练/验证病例的源NPZ身份、缓存元数据、[1,256,304,304]float32缓存和原数据/255的逐值一致性。复用原只读缓存。训练/验证标签在annotations/，50人正式测试标签在test_annotations/。运行绑定写入deployment.json，正式开始后绑定与源码保持一致。

## 验证、选模及报告

每5轮固定10名验证患者完整推理，共E5到E200的40次。各病例计算浅层最大投影SSIM与浅层、深层、ILM–BM均值投影SSIM的等权均值，再按患者等权平均。用这个selection_projection_ssim最大值选best，同分保留较早轮次。A/B完全相同。全部指标和图像使用各自同一份best。latest与E200是补充预算结果。

报告完整3D、全部304张物理ZX B-scan的逐片后整卷平均，以及七种投影的MAE、PSNR、SSIM。主标准用未量化[0,1]与data_range=1。体积是3D SSIM，B-scan和投影是2D SSIM，win7均匀窗口、样本协方差。3D SSIM分块附带完整三体素halo，按有效中心加权，数学窗口与直接整卷一致。患者等权平均，PSNR先按对象/患者计算。

额外GT范围体积及XOCT式量化算式沿用项目metrics.py并单列。XOCT式补充在项目Z256网格与固定划分上同时量化GT/预测，原论文的数据网格与标注适配细节有差异。B-scan采用TransPro逐切片再整卷的聚合顺序，固定范围和窗口是项目选择。

标注层内均值的文献依据来自XOCT第3.1节式1。XOCT公开方法还含对抗和感知损失，本实验的FM、损失系数、监督时刻及选择规则均为本项目设计。

## 断点、预测留存与正式测试

每个完整训练轮先原子保存trained_pending_validation.pt。验证或提交中断后，从该完整训练轮恢复验证。完成提交后保存latest、每10轮归档，以及每次验证最佳的完整归档。检查点含模型、AdamW、随机状态、源文件、实际版本、绑定和已消费输入身份。轮内中断会从最近完整轮或已训练待验证轮恢复，未提交的步日志保留为中断证据。

验证保留完整指标、逐B-scan、二维浮点数组和同窗图，三维数组计算后释放。正式训练200轮完成后，通过显式freeze和test运行固定50人。正式测试保留完整float32三维NPZ、所有投影、切片、指标和图像。重试检查身份并复用已核验病例。每组全部正式三维原始载荷约4.4GiB，压缩后的大小取决于实际预测。

两个tmux会话各自运行，A/B默认同一已分配可见GPU并行。恢复和日志互相独立。上传、准备验收、tmux创建、实际训练步、预算完成和正式测试分别记录。交付目录直接同步。
