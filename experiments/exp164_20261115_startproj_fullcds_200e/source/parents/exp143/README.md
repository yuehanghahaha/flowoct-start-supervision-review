# exp143_20261112_startproj_endvoxl1_200e

Parent `exp018_20261027_3dfm_start_zproj_200e`. New training from scratch, seed 2026, 200 epochs × 200 successful updates. Fixed 140/10/50 patients. This is one of the three requested random-time endpoint L1 runs. Historical exp017 and exp018 are the comparison references.

`xt=(1-t)*OCT+t*GT`, `v=model(xt,t,OCT)`, `yhat=xt+(1-t)*v`. Velocity MSE remains active everywhere. Added endpoint L1 mode `full`, coefficient 0.05. L1 uses the raw signed endpoint. No extra integration or network pass is used. On a straight path this endpoint error equals `(1-t)*(v-(GT-OCT))`; the extra L1 changes the norm, time weighting and (for ROI) spatial weighting. It does not alone test whether supervision of velocity is intrinsically inferior to image supervision.

Parent time distribution is preserved with exact-t0 fraction 0.5. Projection mode `global`, weight 0.1, exact t0 only. exp017 arms retain 150 epochs, exp018 arms 200 epochs. All retain base16 2.098M U-Net, 256×64×64 crops, AdamW lr2e-4, no weight decay, clip1, Euler8/Hann overlap0.5 full 256×304×304 validation.

Content-box arm uses each physical ZX B-scan. For prediction and GT separately, detect first/last rows with row mean > 0.05×max, then first/last columns over those rows with mean > the same threshold. Take the union, expand Z by10, clamp to the patch. If row detection is empty, the box covers the whole B-scan. If only column detection is empty, the box spans the full width over the detected rows. Detection uses detached clamp[0,1] only. The rectangle retains dark internal pixels and is not a vessel mask. Average absolute error within each rectangle then equally average all Y slices. This is a documented 3D adaptation of the retained public FlowOCT crop helper. The predicted box can widen the ROI early in training.

Numerics use float32 parameters, inputs, optimizer and losses, BF16 CUDA autocast for model operations, float32 endpoint and stitched ODE state, no GradScaler. TF32 matmul/cuDNN allowed, cuDNN benchmark on, deterministic off. Historical parents used strict float32 with TF32 off and deterministic cuDNN. The comparison with historical results includes that precision and backend difference. Real A800 benchmarks and finite-gradient checks must pass before formal training.

Validation every5 epochs across all10 patients. Original main selection is maximum ILM–OPL max-projection SSIM, ties retain earlier. The same chosen checkpoint supplies every metric and figure. Reports include complete MAE/PSNR/SSIM for 3D, 304 B-scans and seven en-face projections, range1, native layer rasterization, uniform SSIM window7/sample covariance, equal patient averaging. Additional metrics are labeled. Intermediate 3D arrays are released after metrics, never cached to disk. Initial/latest/every10/selected best archives preserve model, optimizer, RNG, source and consumed input identities. Formal test is separate and requires frozen full-budget best.
