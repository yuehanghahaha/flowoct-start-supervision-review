# 四组正式科研实验协议

本套件以当前项目exp001的体素3DFM为直接来源。新四组从头独立训练，不接入旧AMP训练权重，不沿用先验/残差大网络分支。exp016/017/018/019分别为起点200轮、均匀时间150轮、起点加Z投影200轮、起点加区域投影200轮。源代码及新配置固定后不覆盖旧实验。

## 共同基线与精度

- 原3D U-Net、基础通道16、2,097,521参数；状态和条件均为单通道，固定OCT条件，起始图像仍是OCT。
- 140训练/10验证/50测试，来自`membership.json`的固定患者划分；四组统一重排为该清单顺序。训练不读取测试图像或测试标注，不以测试结果选择设置。
- 固定除255、ZYX、Z=256；沿用原配对预处理。完整视野为256×304×304，不对XY缩放或裁掉视野。
- 正式训练体块256×64×64，batch1。64×64是直接父基线的设置，为控制变量保留，并非为四开压缩体块；不会自动改为更小窗口。
- 所有网络前向、反向、验证和推理均FP32。没有autocast启用分支、GradScaler、TF32或精度自动回退；指标求和使用FP64以提高数值稳定性。
- AdamW、固定lr=2e-4、weight_decay=0、总梯度范数裁剪1。每轮200次成功更新；FP32非有限损失/梯度立即保留故障记录并停止，不跳过更新计数。
- 四组seed=2026、相同初始化和每轮病例/裁块随机序列。时间采样使用独立RNG，因此删除t=0不会连带改变病例和裁块。固定seed不等于跨硬件/库版本逐位相同，也不替代多随机种子重复。

## 流匹配与起点

```text
c = OCT, y = OCTA
x_t = (1-t)c + t*y
L_FM = mean((v(x_t,t,c) - (y-c))^2)
```

exp016/018/019每轮精确100次t=0、100次t∈(0,1)。exp017每轮200次均匀随机t∈(0,1)，不混入精确t=0，不增加其他损失；这才是从同一代码删去起点学习的对应组。每轮是200次有放回随机病例裁块更新，不是完整遍历所有患者一遍。

exp016/018/019各40,000更新；exp017为30,000更新。起点200轮与均匀150轮的全预算最优结果不是等预算消融。四组都保留第150轮和截至150轮的累计最佳快照，可在相同30,000更新前缀下比较起点效果。全部配置仍按用户要求完成各自预算。

## 第3、4组：匹配的Z轴投影定义

两组都采用ILM–OPL层内沿Z最大投影，和数据集B5及血管标注对应。它是沿Z投影，但**区别于历史旧实验的全深度均值L1**。这样第3与第4组只差区域额外权重，不混杂最大/均值、层范围和不同网络。历史全深度均值实验仍保留，不能把这里的新投影称为对其原样复现。

仅在精确t=0更新上，复用同一次网络前向构造：

```text
y_hat0 = c + v(c,0,c)                 # 不截断，不另做网络前向
P(y) = max_Z y within ILM–OPL
L_global = mean_valid_rays |P(y_hat0)-P(y)|

exp018: L = L_FM + 0.1 * L_global
exp019: L = L_FM + 0.1 * (L_global + 1.0 * L_nonlarge)
```

随机时间更新仍只使用L_FM；不存在把含GT的随机时间输入当作纯OCT生成来监督投影的做法。辅助项由单步终点估计定义，不等同于完整Euler8结果，因此验证必须评价真正的八步自由生成。

权重0.1和区域系数1.0是本批实验明确预设的研究假设，不宣称已经验证最优，不从50例测试图确定。两组不加入边缘损失、分割辅助头、小波、噪声先验或rollout损失。

## 区域与坐标

训练使用数据集已有标注。实际本地单任务`GT_Capillary`几乎包含全部`GT_LargeVessel`，不可直接视为互斥的纯毛细血管标签：

```text
V = GT_Capillary > 0
M_large = GT_LargeVessel > 0
M_nonlarge = V AND NOT M_large
M_background = NOT (V OR M_large)
```

nonlarge指非大血管标注区域，不声称是按物理直径重新测量的纯毛细血管真值。数据集细网标签也含模型辅助处理，不等于完全无标注误差。

L_nonlarge只在该区域的有效投影像素上求平均。裁块中该区域为空时，这项取0，并记录有效像素数；L_global保留，主干和背景仍受约束。三类区域不作各1/3等权。训练集患者宏平均区域面积约35.6%/6.6%/57.8%，简单三等权反而可能相对抬高大血管权重。

BMP按XY存储；模型张量及Layer为ZYX/6YX。因此训练掩膜先转置为YX，再与OCT完全相同地裁块。评价投影按父代码转回XY，与原BMP对应。层标注为MATLAB一基的native640坐标，用Z256体素中心映射和闭区间选层，不把边界粗略四舍五入为新整数层。无效Z位置在训练max中填−inf，避免无标注层的零值吞掉负预测的梯度；空射线不计辅助均值。

层和血管标注只用于损失与事后评价。生成模型输入只有OCT，不接收GT层、GT掩膜或真实OCTA。

## 验证、指标和选模

每5轮及最后一轮，在完整10人验证集上做完整256×304×304的FP32 Euler8。沿用原50%重叠滑窗、正Hann权重、每一步先拼接全局速度再更新状态；仅最终截断到[0,1]。不以单块或低分辨率推理代替整卷评价。

标准指标完整报告：

1. `volume_mae/mse/psnr/ssim`：完整3D体积，原始固定/255浮点，data_range=1，SSIM为三维窗口7、uniform权重及默认sample covariance；PSNR由逐体MSE计算，零误差MSE下限1e-12。
2. `reference_volume_psnr/ssim`：另报官方FlowOCT工具函数采用的逐患者GT.max−GT.min范围。SSIM同样为完整3D、窗口7。它和固定范围1的值分别命名，不能混用。GT为常量时参考范围指标未定义，记录null。
3. `projection_*`、PCC和`region_*`为额外诊断：全深度均值/最大值、ILM–OPL和OPL–BM最大投影，均固定data_range=1；区域强度误差和偏差并非细血管分割Dice或召回率。

两列PSNR均沿用本项目1e-12的MSE下限；完全零误差时返回有限上限，这一点与官方函数的正无穷结果不同。正常非零误差大于该下限时公式相同，输出中不把此约定隐藏为完全逐行复用官方函数。

先逐体计算，患者内平均，再患者等权宏平均；不把所有患者体素拼成一个PSNR，也不把投影SSIM当作体积SSIM。四组主best均选择**验证集ILM–OPL SSIM最大值**，沿用直接父实验以比较当前血管投影目标；这与官方FlowOCT按验证体积PSNR选best的规则不同。另存`best_reference_psnr.pt`供预先明确的参考对照，不能测试后在两者之间择优挑结果。

本项目四组是现有3D基线的受控对照，并非原2D Haar FlowOCT模型的完全复现：原论文的模型、视野处理、归一化、样本暴露量等不同。因此即便增加参考指标列，也不能据此宣称与论文数值已完全同协议。

## 科学输出与恢复

- 每次完整验证都保存所有患者的**完整3D float32预测NPZ**、原始二维投影数值、完整指标JSON/CSV、5种视图的GT/预测/误差图和HTML报告。NPZ是无损科学数组存储，不是交付打包ZIP。
- 每轮保存latest；每10轮保存正式断点及累计最佳，包含第150轮；训练完成保留第200/150轮正式状态。保存model、AdamW状态、轮数、成功更新数、配置、源文件指纹和库版本；输入文件在首次正式使用时记录SHA256。
- `trained_pending_validation.pt`额外保留刚完成训练但尚待验证的状态。常规resume以latest完整轮为边界，未完成轮可重复，重复的未提交日志另存为中断证据；不会把它们计入额外成功更新预算。不存在“丢弃一半更新以省时间”。
- 不自动删正式断点、预测或科学图。每个完整体的float32预测未压缩约90.25MiB；本四组共有约1500个逐轮验证预测，另有最终测试输出，应在服务器安排足够磁盘。压缩后的实际大小取决于内容。
- 完成预算后显式`freeze`，再显式`test`。测试不自动运行，也不参与代码冒烟、检查点选择或超参数决定。项目历史已看过同一50例测试，不称为全项目从未接触的外部盲测。

## A100四开

同一张A100上四个独立进程逻辑上可行：模型、优化器、RNG、日志和输出完全分离，只共享只读输入。四组使用独立tmux会话，不是DDP，不共享梯度。多个进程会共享显存和计算资源；没有MPS时通常由CUDA上下文分时调度，不能把四开理解为总吞吐必然提高四倍。

不设置每进程20GB上限，不自动缩块/减轮/切换AMP，不自动启动MPS或改变MIG。若正式训练确实发生OOM，会记录当时空闲/总显存及峰值并停止该任务，保留完整断点，交由用户决定资源安排。按用户要求，本次没有短程训练、验证模型替代代码或强制先跑check门槛。
